# Unidad 01 — Proyecto académico de Desarrollo Web

Este repositorio contiene mi proyecto escolar de la Unidad 01 de la materia de Desarrollo Web. La versión actual corresponde a la configuración inicial de un backend en Java con Spring Boot.

## Alcance actual

- Clase de inicio de la aplicación Spring Boot
- Inicio del servidor web integrado en el puerto 8080
- Prueba básica de carga del contexto de Spring

El proyecto forma parte de un trabajo escolar en desarrollo. Por ahora, el repositorio contiene la base de la aplicación y todavía no es una aplicación web completa.

## Tecnologías

- Java 21
- Spring Boot 4.1.0
- Apache Maven

## Requisitos

- JDK 21 o posterior

## Cómo ejecutarlo

En Windows:

```powershell
.\mvnw.cmd spring-boot:run
```

Después, abre [http://localhost:8080](http://localhost:8080).

## Cómo ejecutar las pruebas

En Windows:

```powershell
.\mvnw.cmd test
```

El repositorio incluye Maven Wrapper, así que no necesitas instalar Maven por separado.
